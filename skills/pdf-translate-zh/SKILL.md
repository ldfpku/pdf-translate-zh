# 工业技术 PDF 出版级中文翻译（pdf-translate-zh）

把工业技术英文 PDF 做成**出版级中文版**：内容忠实、表达地道、版式服务于中文
阅读、插图纯净、勘误可追溯。质量目标三词：**准确、一致、流畅**。

> **核心公理**：忠实的对象是**内容与表达方式**，不是英文版的物理坐标。
> 物理断行、条目间距、为塞回英文框而缩的字号，都是导出痕迹，不是内容。
> 只有「版面本身就是内容」的页（工程图纸、可填写表单、统计图表）才保位。
> 规模化时再加三根支柱：模板册**翻结构不翻页面**、多代理流水线但**术语/坐标/
> 装配/闸门中心化**、图-图题映射从源版几何取**真值**（`references/pipeline.md`）。

本技能每条规则都来自实测踩坑；很多坑**静默失败**（闸门全绿、渲染前毫无征兆）。
主干只讲流程与决策，细节在 `references/`，按下表**用到哪一路再读哪一册**：

| 分册 | 何时读 |
|---|---|
| `industry.md` | 每份文档第 0 步：行业识别与行业译法惯例 |
| `pitfalls.md` | 开工前读顶部「⚠ 毁页级速查」；其余按所走路线读对应章节 |
| `overlay.md` | 有 P 级页（图纸/表单）要原页叠印时 |
| `text-layout.md` | 所有路线的中文排版（断行禁则、列表、字号取齐、注记块） |
| `tables.md` | 有表格时（叠印的 `tablefix` / 重排的列宽与上下标） |
| `figures.md` | 插图里有字（矢量/描边/位图烧死）、要裁图、要超分或重绘件号气泡时 |
| `cover.md`、`toc-and-nav.md` | 有封面、目录，或文档 ≥ 20 页要加跳转链接与书签时 |
| `formulas.md` | 有算式、Symbol 造字区字符、上下标、分数时 |
| `slides.md` | PPT 导出的横版讲义（S 级） |
| `pipeline.md` | 模板册（同版式重复 N 次）、散文 ≥ 30 页、或多册并行时 |
| `scripts/README.md` | 模块地图、依赖与可移植性细节 |

> **数据合规（开工前看一眼）**：`scripts/` 全在本机运行，不上传文档内容；但**译写由你
> 当前所用的模型完成**，云端模型会收到原文与译文。文件看起来是客户资料、带保密/专有
> 标记（Confidential、Proprietary、NDA、Export Controlled、ITAR/EAR 等）或含个人信息，
> 而你不确定当前是否在用本地模型时，开工前用一句话提醒用户：这类资料交给公有云模型处理
> 须符合当地法律与合同约定，敏感文档宜改用本地部署的模型（仓库 README「本地模型方案」）。
> 由用户决定是否继续；提醒一次即可，不要反复追问、也不要替用户拒绝。

## 快速开始（每份文档都按这个顺序走）

```bash
S=<本技能目录>/scripts                    # Windows: set S=<本技能目录>\scripts
# 下文的 python：macOS / Linux 写 python3，Windows 写 py 或 python
# 环境不用手动配：每个入口脚本开头都会自动补装缺少的依赖（装进技能私有目录，不碰系统 Python）、
# Linux 上自动转换中文字体；需要插图超分时自动按显卡装 torch 并下载权重。不要让用户去装东西。
#   新机器想一次配齐（可选）：python $S/bootstrap.py [--sr]；机器上连 Python 都没有：
#   sh <技能目录>/setup.sh  /  powershell -ExecutionPolicy Bypass -File <技能目录>\setup.ps1
#   工具调用有时限（如 180 s）时，首次的 `bootstrap.py --sr`（torch 可达 2.5 GB）放后台跑：
#   nohup python3 $S/bootstrap.py --sr > setup.log 2>&1 &   然后轮询 setup.log
python $S/translate_pdf.py <file.pdf|目录>  # 定级 + 素材提取 + 生成内容层骨架
#   产出 <PDF 所在目录>/translated/<名>/{data,figures,qa,content}/
#   有插图时先目检 qa/contact_*.png（无插图看 render/p*.png），通读 data/prose_dump.txt、
#   tables_readable.txt、route.json
#   → 行业识别（§1 第 0 步）→ 按定级写内容层：R/H 级写 content.py + terms.py；
#     P/S 级 `build.py --dump` 导出待译单元 → 写 <名>_dict.py + terms.py（§2）
python <工作区>/content/build.py            # 出稿 + 全部闸门；任何 FAIL 返回非 0
python $S/preview.py <译稿.pdf> <出图目录> --sheet   # 整册缩览拼贴，逐页目检
```

脚本一律**直接调用**，不要从头再写 —— 与文档无关的部分已写好并经 28 份文档
全量交付验证。换文档只替换内容层（译文、术语、勘误），不改引擎；需要改引擎时
改完必须跑 `selftest.py` 并做成品对成品回归（§9）。

## 0. 交付形态与质量目标

| 维度 | 目标 |
|---|---|
| 行业 | 先识别行业再翻译，锁定该行业术语库与译法惯例；判定与依据写进附录 A |
| 准确 | 零遗漏零增删；数值/单位/型号/标准号/零件号原样保真；低质原文回译还原本意；凡修正必入勘误 |
| 一致 | 术语全文统一、首现附英文、同物同名（规则优先、字典兜底）；语体全册一致 |
| 流畅 | 长句拆短、被动转主动；shall/must/should = 应/必须/宜；工序用祈使句；全角标点由 `zh()` 保证；断行守禁则 |
| 版式 | 正文 10.5pt 左右、1.5 倍行距；任何中文 ≥ 6.5pt；图题在下表题在上；文本类用 A4；页数由内容决定（约原版 70~85%）；品牌色与页眉页脚沿用 |
| 插图 | 图内文字全类译出、逐幅漏译排查归零；原样保真不重绘；图幅权重跟随原版；尺寸代号与商标不译；< 150 dpi 位图先超分再回叠；件号气泡判读对账后统一重绘 |
| 结构 | 表格 100% 译文重建（不以截图充当）；目录点引线对齐 + 跳转链接；列表层级还原 |
| 可追溯 | 正文之后附录 A《译校勘误说明》、附录 B《中英术语对照表》，各自另起一页、不与正文同页（§10） |
| 可复现 | 提取 / 词表 / 装配三层各自可重跑；工作区路径全相对，拷到别的机器可直接重跑 |

## 1. 定级与路线

### 第 0 步：行业识别 → `references/industry.md`

按证据强度：①引用的**标准号族**（API/SY = 石油钻完井；ASME B&PV = 压力容器；
AWS = 焊接……）②**产品域词汇**（motor/stator/rotor/jar/BHA → 井下工具）③单位制与工况词。
选定后锁三样：**行业术语库**（jar=震击器、fish=落鱼、trip=起下钻、string=管柱——外行直译
必错的词在这一层拦住）、**译法惯例**（`*-sub`=「××接头」、`housing`=「壳体」）、
**语体**（规范条文体 / 操作指令体）。

### 第 0.5 步：版面级别（`translate_pdf.py` 已写入 `data/route.json`，也可单跑 `route.py`）

对每页问三问：**坐标有语义吗**（尺寸线、剖视图）？**格子要回填吗**（表单）？
**删掉版式重排后信息有损吗**（统计图表）？

| 级 | 判据 | 处置 | 机制 |
|---|---|---|---|
| **R 语义重排**（默认） | 三问皆否：散文/步骤/普通表格 | 抽内容结构 → 译 → 按中文版式流式排版 | `driver.Job(flow=True)` |
| **H 混合** | 同一文档 R、P 页并存 | 逐页分流：正文页重排、图纸表单页叠印，最后按序拼合 | 两者皆用 |
| **P 版面保持** | 任一问为是：图纸/表单/图表 | 原页叠印，坐标即语义 | `hybrid_overlay` / `dwg_overlay` |
| **S 幻灯片** | 横开 + 大字号的 PPT 导出 | 整页保位 + 页内列表**整列重排** | `slidekit`，见 `slides.md` |

页级信号：图面 ≥ 70% 或路径 ≥ 3000/页 → 图纸；勾选框 ≥ 15/页 → 表单；
文本层几乎为空 → 文字已转曲线或是扫描件，只能视觉转录后重排。

- ⚠ **不要**用「路径数/字符数」比值，也**不要**拿扁长矩形当填写横线——表格单元格
  也是扁长矩形，实测会把 8 份纯文字档全判成表单。
- ⚠ 旧版「页数 ≥ 20 → 叠印」判据已**作废**：重排不追坐标，成本与页数脱钩，长手册
  反而是重排收益最大的一类。
- S 级是 P 与 R 的混合：照片位置、引出箭头、引注落点是内容（保位）；条目间距是按
  英文行数排的（整列重排）。逐条钉回原坐标会同时产生空洞与压叠，且闸门不报。

**重排后页码与原版脱钩**：文内交叉引用一律改按**节号/图表号**；目录按译版页码
自动生成；附录加「译版节号 ↔ 原版页码」对照表。

**H 级拼合**：R 部分用 `build.py` 出稿，P 页用叠印在原页上出单页，按原顺序
`insert_pdf` 拼合；目录链接与书签在**拼合（及附录合并）之后**再加（§5）。

### 第 0.75 步：模板册判定

抽 3 页比对「字段标签集合」：同一模板重复 N 次、只换数据（规格页/数据表册/检验记录）
→ **提取-重建制**：标签驱动结构化提取、数值文本层直取零转录、标签字典闭集译一次全册
生效、提取值与源页逐 token 对账 = 0。见 `pipeline.md` §1。

### 第 0.9 步：规模判断

散文 ≥ 30 页或模板册 ≥ 20 单元时上**多代理流水线**：翻译代理分块并行（结构化供料
+ 行业术语表 + 输出 schema + 原文笔误回收进勘误），视觉代理转录图内文字（机器给框、
代理读字、坐标禁自造）。**行业判定/术语/坐标/装配/闸门永远中心化**。多册并行时先统一
行业判定与跨册术语底座、冻结后再一册一代理。见 `pipeline.md` §2、§3。

## 2. 引擎与内容层

### R 级（默认）：`content/build.py` + `driver.Job(flow=True)`

`translate_pdf.py` 生成的骨架已是可运行的 R 级构建：

| 文件 | 写什么 |
|---|---|
| `content/content.py` | `CHAPTERS = [[块, …], …]`：每章一个块列表，**按语义组织**（一段一个 `("p", …)`，一项一个条目） |
| `content/terms.py` | `GLOSSARY`（附录 B）、`JIA/YI/BING`（附录 A 甲乙丙）、`WHITELIST_ADD`、`TOKEN_IGNORE` |
| `content/build.py` | `Job(...)` 配置：幅面、页眉页脚、`flow=True`；一般只改 name/抬头 |

块 DSL（全部文本自动过 `zh()`）：`("h1"|"h2"|"h3", t)` `("p", t)` `("bul", [..])`
`("ol", [..], "alpha")` `("step", t)` `("kv", [(k, v)])` `("box", t, 类型[, 标题])`
`("fig", 文件, 宽pt, 图题)` `("tbl", 工厂, 表题)` `("sbs", 左, 右, 左宽)` `("pb",)` `("cpb", 高)`
`("toc", "目录", 层级)`（自动目录）`("mark", 书签标题, 层级)`（只落书签）`("keep", [块…])`（步骤与其插图不分页）。
完整列表在 `scripts/render.py` 顶部。警示框按原版信号词选类型并自动加标题（正文里别再写一遍）：
NOTE→`note`「说明」、CAUTION→`caution`「注意」、WARNING→`warning`「警告」、DANGER→`("box", t, "danger", "危险")`；章与章缺省接排，长手册要每章另起页设 `Job(chapter_break=True)`。

- 表格用 **lambda 工厂**并传 `width=FW`：`("tbl", lambda: render.grid_table(rows, [3,1,1], S, width=FW), "表 2-1  …")`。
  两趟构建会排两遍，复用同一 Table 实例第二趟会抛 LayoutError；不传 width 可能冲出版心。
- 品牌色在 build.py 里 `zhlib.set_brand(primary=, dark=, rule=)` 换，不改引擎；
  无徽标图时 `Job(logo_text="…")` 写品牌文字。
- P/H 级的 1:1 装配用 `Job(flow=False)`：每源页一个块列表，逐页实排必须 = 1 页。

### P 级：叠印路线（先读 `references/overlay.md`）

`translate_pdf.py` 判为 P/S 级时，生成的 `content/build.py` 就是叠印构建 + 六道关：

1. `python content/build.py --dump` → 待译单元写进 `content/pending.txt`（键 = `units_of()` 清理后的串）；
2. 在 `content/<名>_dict.py` 的 `D` 里写译文（量大分批写 `<名>_b01.py`…，先加载者胜）；
   `""` = 保留原文；尺寸/件号/螺纹代号/标准号原样写进译文；
3. 在 `content/terms.py` 里写附录数据（与 R 级同格式：`GLOSSARY`、`JIA/YI/BING`）——叠印正文之后自动追加附录 A、B，各自另起一页（§10）；
4. `python content/build.py` → 出稿 + 闸门，未命中清零为止。合法保留的英文（公司名、人名）
   写进 build.py 的 `WHITELIST`；明细表要真网格重建时填 `TABLE_PAGES`（先确认 `tablefix.regions()` 认对了表）。

| 模块 | 作用 |
|---|---|
| `hybrid_overlay.py` | 总装：三通道分区 + 排版记号 + 几何对齐判据；`build(..., size_from="span")` 写入字号取源 span 真字号 |
| `dwg_overlay.py` / `text_overlay.py` | 行级 / 段级通道 |
| `keyclean.py` | 待译键清理（拼点导线、拼截断行、归一 PUA、折叠重复词） |
| `tablefix.py` | 表格真网格重建（叠印之后逐页开启） |
| `reflow.py` | 标准重排通道：整块抹掉按块 DSL 重排、区域内字号统一（原版自身版式不佳时） |
| `dwgnote.py` | 工程图标题栏「除另有规定外」注记格（多行对齐、矢量 ±/∨ 时必须重排） |
| `batchwork.py` | 分批词表 `load/dump/stat` + **重复键检查** `dupes()` |
| `fontkit.save_subset()` | 最后一步：字体子集化后存盘（CFF 字体原生子集化静默失败时自动换 fallback） |

**导键与装配必须共用同一个 `units_of()` / `norm()`**——键的产生方式两边不同，词表
就永远命中不了（这是词表白写的最直接死法）。

客户专属的术语表、页眉块、白名单放在各项目自己的内容层里，不要改进技能引擎。

## 3. 附图文本 → `references/figures.md`

按**能不能提取**分三类：

| 类 | 判别 | 处置 |
|---|---|---|
| A 矢量真文字 | `get_text()` 里有 | redaction + 原位写中文 |
| B 描边曲线 | 文本层无、`get_drawings()` 有密集小路径 | `vectext.runs()` 按笔画连通块定位 |
| C 位图烧死 | 文本层无、落在嵌入位图内 | `vectext.inkbox()` + `genraster.py` |

- **R 级最短路径**：`extract.py` 已抹掉图内矢量英文并记下坐标（`data/figures.json`），
  在 `content.py` 写 `LABELS_ZH = {英文: 中文}`，构建时自动同源回叠（`figures.md` §10.1）。
- **C 类首版必然漏译且自检查不出来**。唯一办法是**逐幅全查**（`figlabel.sweep`）：
  每幅检测全部文字块，减去已处置区域，余下描红出核查图人工确认，合法保留录白名单，
  复跑到 0。不要用「矢量标注 = 0 才查位图」筛选——一条矢量图题就让整幅躲过排查。
- **裁图先求真实视觉范围**（`figcrop.safe_extent`）：标签与引线常画在位图 bbox 之外。
  回叠坐标与裁框**同源**（`figlabel`），绝不手估像素框。
- ⚠ **裁框必须过净空判据**（`figclip.clearance` + 常驻 `checks.check_fig_clip`）：裁框
  ∩ 源页未处置文本 = ∅。否则半截英文图题被裁进位图，文本层看不见，全套闸门不报。
- 四条硬教训：必须拿**源 PDF** 量墨迹框（成品上量到的是中文自己）；带黑边框的粗框
  先内缩；竖排标注给转角；粗框宁大勿小但不能碰插图。
- 尺寸代号（`ØA`）、件号数字、商标保留不译；斜体注记按含义译。
- **画质**：有效分辨率 = 像素宽 ÷ 放置宽(pt) × 72。< 150 dpi → `sr.py` 超分 4 倍后再检测回叠
  （后端自动选 torch → onnxruntime → Lanczos 兜底，处置方式记在 `sr_report.json`，附录 A 丙照实写，
  Lanczos 不得写成「超分」）；
  ≥ 300 dpi 不动；带独立高分辨率软掩膜的徽标按掩膜重建、不超分。回叠字号按行高中位数
  （`tightbox.tighten`）。
- **件号气泡**：逐个放大核读（`bubbles.sheet`），与步骤文字/零件表对账后
  `bubbles.redraw` 原位统一重绘，`bubbles.residue_check` 旧环残留判据全书归零；判读依据与
  存疑写进附录 A 乙。
- **R 级位图插图一条龙**（`figpipe.py`，手册/作业指导书里的低清渲染图、截图）：
  `extract`（按 xref 提原图，软掩膜合成白底，记有效 dpi）→ `sr.py --places data/images.json`
  → `detect`（出带框号的核查图 `qa/det_*.png`）→ 内容层写 `labels_zh.py`（按**框号**给译名 /
  KEEP / SKIP，件号气泡写 `BUBBLES`）→ `apply`（回叠 + 气泡重绘，大图出 JPEG）→ `sweep`
  归零 → `sheet` 气泡拼贴目检。未列出的框按漏译报错。完整示例见仓库 `examples/showcase-swi/`。

## 4. 表格 → `references/tables.md`

**一律用译文重建，不截图。** 叠印路线逐格叠印不够（MuPDF 行聚组把相邻两格并成一条，
每格各自缩号 → 同表字号忽大忽小），用 `tablefix`：按行带定列 → 按词心归格 → 查词表 →
抹全表文字（线框不动）→ 全表统一字号重排。

- 格内文本必须从**源页**取（`src_page=`）；对齐**按列**定不按格；必须在叠印之后、逐页开启。
- 重排路线：列宽有「原子记号」下限（`2020-08-17`、`80020610` 不许被劈开，`grid_table`
  已自动 `fit_cols`）；上下标压浅下沉并补行距（`P()` 已自动处理）。
- ⚠ 别用 `find_tables()`：伪表会让整幅插图静默消失，按线框几何自求。

## 5. 封面与目录 → `references/cover.md`、`references/toc-and-nav.md`

- **不写绝对 pt 值**：尺寸只由实测量（版心四界、原块 bbox、原字号）、比例系数、搜索所得
  （自动降号试排）推出。写死的 540/72/10pt 换一份文档就失效。
- 默认叠印保位，命中判据才重排：目录被导出成单条长串/引线残留/页码落行中 → 整页重排；
  封面中译标题块宽 < 原块 0.55 或折行多于原版 → 只重排标题块。原版没有就不新造。
- **R 级重排：目录与书签由引擎生成**。标题块（sec/h1/h2）自动落 PDF 书签；内容层放
  `("toc", "目录", 收录层级)` 即按译版页码自动排目录（点引线收敛、整行可点跳转，附录 A/B 自动收录）；
  工序步骤等只要书签不进目录的用 `("mark", 标题, 层级)`。有目录时两趟构建自动多跑一趟定行数。
- **叠印路线 ≥ 20 页强制加跳转链接与书签**（`toclinks.add`，分节页码用 `use_labels=True`，文件编号
  索引用 `code_links`）。链接在合并附录**之后**加；`add()` 幂等（「链接数 = 书签数 × 2」
  是重复叠加的指纹）；书签层级至多深一级（PDF 大纲硬约束），缩进不动。
- 点引线**实测收敛**或**从右往左画**；同页引线/右对齐条目的写入框右端取齐到公共 x。
- 八道判据 `toccheck` / `tocsweep`：条目数 = 链接数 = 书签数、矩形不重叠、**落点回验**、
  页码右端离散、同级左界、保留项、残留英文、封面对齐。落点回验专抓原版目录页码陈旧、
  目录与正文译名不一致。

## 6. 中文排版 → `references/text-layout.md`

- `insert_textbox` **不会在中文里断行**（只在空格处断）→ 按禁则**预折行**。
- 同一行字号**向下取齐**（各条最大可放字号取中位数，再各取 min）；写入框可向下借空白。
- 合并单元里的多条目用**显式换行**；注意/警告框中文可一行，不必同步英文行数。
- 原版下划线标题 → 抹线 + 加粗；表单标签右对齐贴到填写线前。
- 译文里**不许出现 Markdown 星号**（`**切勿**` 会原样印出去）。
- ⚠ 旋转单元不做 y 方向的任何手脚（预折行、借空白、同行取齐都只动 y，而对 `rotate=`
  的单元 y 正是行长方向——整列文字会被推出页面，闸门不报）。

## 7. 公式与特殊字符 → `references/formulas.md`

- 多行算式用 `RALIGN` 逐行还原；行高系数分档（折行 1.90 / 自带换行 1.34）。
- Symbol/Wingdings 造字区（U+F020~F0FF）一律先归一到真 Unicode，且归一做在**导键与
  装配共用的 `norm()`** 里；残留码位由 `keyclean.PUA_LEFT` 报出，不许静默。
- 中文字体普遍缺 U+2082 等下标字符 → 化学式下标**真排版**（`slidekit.subscript_pass`）。
- 堆叠分数 `4 1⁄ … 2` 重组为 `4-1/2`，`keep` 里的分数规则必须带尾锚 `$`。
- 中文判据要含全角标点（`[一-鿿]` 不含 `。`）。
- 符号字形随机器字体而变：用 `zhlib.pick_glyph("•●·")` 挑本机字体有的。

## 8. 术语、词表与译法

- **规则优先、字典兜底**：零件描述先列唯一串（`uniq_desc.py`），写「正则规则 + 精确字典」，
  断言未命中 = 0；特化规则排在泛化规则之前。
- 空串 `""` = 保留原文；真要抹掉写单个空格。
- ⚠ `keep` 规则吞掉的条目既不译也不报（`^[A-Z0-9\-]{2,}$` 一次吞掉 398 条）→ 代号规则
  必须**要求含至少一个数字**；写完 dump 一份被吞串人工过一遍。
- 分批词表重复键**静默失效**（先加载者胜）→ `batchwork.dupes()` 交付前必须为 0。
- 语体：规范条文体用「应/必须/宜/不应」；操作步骤用祈使句；术语首现附英文。

## 9. QA 闸门

### R 级

`build.py` 自动跑、任何 FAIL 返回非 0：

| 关 | 判据 |
|---|---|
| 内容对账 | 源版每个数字/件号/型号/标准号记号在译版正文里找到归宿（`check_content_tokens`，附录页不作证）——「零增删」的机器证明 |
| 残留英文 = 0 | 白名单外的英文行；纯单位/代号行（`gpm`、`4-1/2 REG`、`API RP 7G`）自动放行 |
| 缺字 = 0 | 按实际写入的字体逐 span 查 cmap（换机器字体不同也有效） |
| 文本层码位 | 无 U+2011/U+00A0（字体别名让图号「675-200-011」不可检索） |
| 版心外杂物 / 压页脚 / 页码序列 / 避头尾（行首 + 行尾） | 版面硬伤 |
| 页数预算（提示） | 正文页数 ÷ 原版 ≈ 70~85%；明显偏低先查整章漏译 |

另需自查（不在 build.py 里）：段落数/列表项数/表格单元数/图数与源版对得上；每图在
被引用后 1 页内出现、所有「见 X」可解析；有目录时跑 `toccheck` 八关。

### P 级（叠印）：六道关

未命中 / 溢出 / 残留英文 / 缺字 / 重叠 / 保留项失踪，外加文本层码位、词表重复键、
版面保持（幅面不变、矢量图形未被抹）—— 骨架 `build.py` 全部自动跑；全库复查用 `sweep.py`。

### 常驻附加判据

断句体检（`slidekit.orphans`，小写起头/虚词收尾的残条）、残留 PUA、Markdown 星号、
成品体积（涨一个数量级 = 漏了 `subset_fonts()`）、图边净空（`check_fig_clip`）、
页边杂线（`check_margin_rules`）、孤页（`check_thin_pages`）、西文断词
（`check_word_split`）、旧环残留（`bubbles.residue_check`）、气泡判读对账。

### 闸门全绿 ≠ 没毛病

闸门看不见「**位置对不对**」。引擎改动后必须做**成品对成品回归目检**：`preview.py --sheet`
逐页缩览拼贴，整册一眼扫完。

**用户报缺陷时给的页号只是样本**：定根因 → 写一条覆盖全书的机器判据 → 给出
「共 N 处、哪些页」→ 修完用同一判据复验为 0 → 固化成常驻自检。只修点名页既掩盖规模、
也保证复发（实测点名 2 幅，普查 29 处）。

**判据写完必须做负对照**：把修复关掉重建一次，判据必须报得出来——报不出来说明判据是假的
（实测「西文断词」第二稿词表取自成品自己，给自己盖章）。判据也要能容纳自己做的形态变更
（改真下标后 `CO2` 裂成 `CO`+`2`，逐项确认两截都在，而不是一句豁免了事）。

## 10. 附录

**与译文分隔（硬要求）**：每份译稿都附这两份附件，一律排在主体译文**之后**；附录 A 另起一页，
附录 B 在 A 之后再另起一页，任何一页都不同时承载正文与附录（正文末页再空也不接排）。
附件本身可占多页，页码单独编为「附录 A-1…」「附录 B-1…」。成品闸门「附录分页」
（`checks.check_appendix_pages`）复核：A、B 齐全，标题是起始页版心里的第一段文字。
- R 级：`driver` 两趟构建自动完成；`terms.py` 的 `GLOSSARY` 为空时附录 B 缺失 → 闸门 FAIL。
- P / S 级：`content/terms.py` 与 R 级同格式，叠印构建里 `appendix.append_to(TMP, terms)`
  在叠印正文后追加（A4 竖排，与图纸幅面无关）。
- H 级：先按原顺序拼合全部正文页（P 页只能插在附录之前），R 部分若已带附录，拼合时插在
  附录前；也可 R 部分不带附录，拼合完成后 `python $S/appendix.py <成品.pdf> content/terms.py`
  统一追加并跑闸门。

**附录 A《译校勘误说明》**：
- **甲、原文缺陷与勘正**（正文已按勘正后译出）：原文位置 | 英文原文/问题 | 问题类型 | 勘正与译文 | 依据；
- **乙、存疑保留**：无法确证的数值分歧（尤其承压件尺寸）**保留原值、仅加注**，写明与哪张表冲突、须经工程部门确认；
- **丙、版式与插图修复**：提取/排版中的修复动作；**图内位图英文的回叠办法与保留原则必须写在这里**，
  保留项逐类写清理由（相机日期戳、实物钢印/吊牌、尺寸与公差、正文按名引用的符号、钢级与型号代号）。
  处置形态变更时同步改写对应条目。

**附录 B《中英术语对照表》** 由 `terms.GLOSSARY` 自动生成，按类别双栏排版。
行业判定与依据写进附录 A 的引言。

## 13. 跨机器使用

- **环境全自动**（`scripts/bootstrap.py`，只用标准库）：入口脚本与工作区 `build.py` 开头调
  `bootstrap.ensure()`，缺包就 `pip install --target` 进用户缓存下的 `pydeps/<Python 版本-平台>/`
  （不碰系统 Python、不要管理员权限、绕开 PEP 668；PyPI → 清华 → 阿里云依次试；换 Python 版本自动另装一份；
  文件锁防并发；子进程经 PYTHONPATH 继承）。Linux 只有 CFF 中文字体时首次自动转换（约 2~4 分钟，之后缓存）；
  macOS 首次自动把苹方 SC 转成 TrueType（约 30 秒）——不转就只能用华文黑体，° ′ ″ · 全角、粗体不明显。
  Python 3.9（如 macOS 自带的 /usr/bin/python3）只能装到 PyMuPDF 1.26，缺的 API 由 bootstrap 自动补。
  排查用 `doctor.py`（只报告）；`doctor.py --fix` = `bootstrap.py --sr` 一次配齐。
- 设置跟着技能走：把镜像地址写进技能根目录 `config.json`（模板 `config.example.json`：`pip_index`、
  `torch_index`、`sr_url`、`sr_onnx_url`…），每台电脑自动生效；同名环境变量 `PDF_ZH_<键名大写>` 优先。
- 中文字体由 `scripts/fontkit.py` 解析：环境变量 `PDF_ZH_FONT` / `PDF_ZH_FONT_BOLD` →
  技能 `fonts/` 目录 → 转换缓存 → 系统字体（Windows 雅黑、macOS 苹方（转换后）/华文黑体、Linux Noto/思源/文泉驿）→
  PyMuPDF 内置 Droid Sans Fallback；CFF 字体与有 ASCII 别名的字体会被自动排到后面。
  **不要在脚本里写字体路径**，一律 `fontkit.find("zh")`。
  要各机器产出一致，把同一套字体放进 `fonts/`。
- 插图超分**首次真正需要时**（有 < 150 dpi 位图）自动装后端：配了 ONNX 模型来源 → onnxruntime（25 MB）；
  macOS → torch（MPS）；有 NVIDIA 显卡 → torch CUDA 版（cu128 → cu126 → PyPI）；其他 → torch CPU 版。
  都装不上就 Lanczos 兜底、流程不断（`sr_report.json` 如实记录）。`sr_autoinstall: "0"` 可关。
  权重（67 MB）依次从 `sr_url` → GitHub → HF 镜像下载并校验 SHA-256；离线放进 `scripts/models/`。
  团队推荐：在一台有 torch 的机器 `sr.py --export-onnx`，把 .onnx 放到自己的存储并写进 `sr_onnx_url`，
  其余机器只装 25 MB 的 onnxruntime（与 torch 结果逐像素一致）。
- 工作区路径全相对，`content/_engine.py` 自动找引擎（或设 `PDF_TRANSLATE_ZH_HOME`），
  整个 `translated/` 目录拷到别的机器可直接重跑。
- 批量回归：`rebuild_all.py <项目根>` / `build_all.py --root <项目根>` / `sweep.py <项目根>`。
