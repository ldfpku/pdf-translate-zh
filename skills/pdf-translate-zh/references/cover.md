# 封面（首页）

> 主干见 `SKILL.md` §5。**封面是全书唯一一处「保留项密度 > 待译项密度」的页面** ——
> 型号、商标、地址、修订号、条码、签署栏全挤在这一页。抹除框画大一点就连带
> 删掉条码，而六道关一处都不会报。

---

## 0. 总原则：不写绝对值

所有尺寸只能由三类量推出，推不出来的就不是规范，是巧合：

| 类别 | 含义 | 来源 |
|---|---|---|
| **实测量** | 版心四界、原块 bbox、原字号、原行距、原对齐方式 | 从**源 PDF** 量（不是从成品量，见坑 ㉚） |
| **比例系数** | 字号级差／留白，以「基准字号」或实测量为单位 | 有默认值，随册可调 |
| **搜索所得** | 基准字号本身 | 自动降号试排，不预设 |

唯一的绝对值例外是**可读性下限**（正文类 ≥ 5.5pt、标注类 ≥ 4.6pt），
那是字体渲染的物理边界，不是版式选择。

---

## 1. 先判断该不该动

**默认叠印保位。** 封面的视觉身份属于原版，动它的收益远小于风险。

仅当下列之一成立才重排标题块：

- 中译标题块的实测墨迹宽度 < 原标题块宽度的 **0.55**（默认值，随册可调）——
  视觉上「偏在一角、右侧空旷」；
- 中译标题折行后**行数多于**原版，且挤压了下方元素；
- 原标题块本身跨越多个字号／多个对齐方式（原版就乱）。

**只重排标题块，不重排整页。** 密级条、地址栏、签署栏一律走叠印。

原版没有封面就**不新造封面**。

---

## 2. ⚠ 对齐：多行块不能一律否掉

这是本项目**一次踩中五册**的坑，且六道关一处不报。

`centered_units()` 曾写着「只认单行」：

```python
# 旧代码
if r.height > 1.8 * max(_s, 6.0):
    continue          # ← 多行块一律不判居中
```

理由看似成立（多行段落的框也可能恰好居中，居中写出来整段变成「居中体」）。
但**封面的副标题堆叠正是多行居中块**：

```
        G2 马达手册              ← 36pt，居中
   6-3/4" Motor with "R" Bearing     ← 20pt，居中  ┐ 同一个多行单元
          & ALPHA Claw               ← 20pt，居中  ┘
        Manual 390 A                 ← 24pt，居中
```

一律否掉，中文就按左对齐落进原框 —— 主标题居中、副标题左对齐参差，整块歪掉。
实测 手册 B／手册 C／手册 K／手册 A／规范 F 五册封面全中。

**行数不是判据，墨迹才是**：

```python
def block_align(rows, tol=2.5, rel=0.03):
    x0 = [r.x0 for r in rows]; x1 = [r.x1 for r in rows]
    mid = [(r.x0 + r.x1) / 2 for r in rows]
    dl, dr, dm = max(x0)-min(x0), max(x1)-min(x1), max(mid)-min(mid)
    lim = max(tol, rel * (max(x1) - min(x0)))       # ← 容差**相对块宽**
    if dm <= lim and dm < dl and dm < dr: return 1  # 居中
    if dl <= lim and dl <= dr:            return 0  # 左对齐
    if dr <= lim:                         return 2  # 右对齐
    return -1
```

- **居中块**：各行中线取齐，左右两端都不齐；
- **两端对齐段落**：左右两端都齐（中线自然也齐）—— 故居中判据要求中线离散
  **严格小于**左右离散，否则会把整段正文判成居中。

⚠ **容差必须相对块宽。** 写死几 pt 会因字号不同带来的字边距差把「明明居中」
判成无定形 —— 实测 手册 B 源封面标题块中线离散 **2.6pt**，绝对容差取 2.5
就差 0.1pt 失手，判据自己变哑、成品歪着也报绿。

## 3. ⚠ 右对齐的一列：单元凑不够数

`right_units()` 按「同一页上右边界相同的单元 ≥ 3 条」聚类。封面上这条会失效两次：

**① 标题堆叠被归成一个多行块** —— 规范 G／规范 F 的三行标题右端同为 x≈523，
却只有**一个**单元，凑不够 `need=3`。补一条兜底：单个多行单元，
若其各行墨迹 `block_align == 2`，直接判为右对齐。

**② 填充率过滤误伤** —— 那条过滤防的是「整格排满的散文」（右对齐只是把参差
从右端搬到左端）。但那种情形各行都贴着单元格左边、**x0 几乎相同**。
封面标题的 x0 是 209／347／359，铺开 150pt，不可能是它：

```python
_spread = max(x0s) - min(x0s)
if len(wid) >= max(2, len(ids)//2) and _spread < 20.0:   # ← 加这个条件
    ...填充率过滤...
```

实测不加这条，规范 G 封面三行标题填充率 0.97 被一票否决，中文右端塌了 140pt。

**③ 孤零零一条的密级标注** —— 封面页脚的密级串在原版是右对齐，正文各页的
同一串却是左对齐；它在封面上只有一条，任何聚类都救不了。这种用
**排版记号**（`RIGHT`）并按页号限定：

```python
def lookup(text, ctx=None):
    z = _typeset(text, _LOOKUP(text), ctx)
    if z and ctx and ctx[0] == 1 and text.startswith("Company Private"):
        return "\x04" + z          # 内容不变、只改对齐，不波及其余 95 页
    return z
```

## 4. 强制左对齐的**兄弟条目**要左界取齐

`LEFT` 记号压过几何判据、按写入框左界排。但写入框继承自原版 ——
原版若是**居中**的多行块，各行 x0 本就不同（行长不等），中文照着排就成了
「左对齐但左界参差」。实测 手册 A 封面两条项目符号差 **4.2pt**。

规则：纵向相邻（间距 ≤ 3 倍行高）且都带 `LEFT` 记号的条目视为同级，
左界一律取齐到其中最左的一个（只收紧不放宽，不引入新的溢出）。

## 5. 各元素的适配式取值

| 项 | ✗ 不要写 | ✓ 适配式 |
|---|---|---|
| 主标题字号 | `20~22pt` | 上限 = **原标题实测字号**（不放大），下限 = 上限 × 0.62，自动降号至装入原块 |
| 行距 | `1.25 ×` | 沿用**原块实测行距比**；原块单行无从实测时回退 1.25~1.35 |
| 对齐 | 「右对齐或左对齐」 | 由**原块墨迹**判定（§2），锚定被判定为取齐的那一边 |
| 副标题字号 | `14~16pt` | 沿用**原版主／副标题的实测字号比**；比值失真时按 0.62~0.78 夹逼 |
| 型号／商标 | 「比中文标题大 1~2pt」 | **保留项不参与中文缩放**，沿用原版字体族与字号 |
| 密级标注 | `7.5~8.5pt` | 按**原框实测宽度**反推能单行排下的最大字号；上限 = 原英文字号，下限 = 上限 × 0.75 |

**为什么主标题不放大**：原版 26pt 的英文标题换成中文后**变短**（同样信息，
汉字少），若同时又放大字号，标题块与页面其余元素的比例关系就变了 ——
那不再是「同源」，是重设计。正确做法是保持字号、让它变短。

**密级标注排不下就换更短的译名，不再降号。** 短名在词表里统一定义，
同一串在封面／页眉／页脚出现多次，**必须同名**。严禁折行、严禁超出原框。

**中文标题的折行规则**（原版没有这个问题，中文才有）：
按语义断，不在「的」「与」「和」后断行；型号／商标不得从中间劈开
（`Super-Jar AP` 不能断成 `Hydra-` / `Jar AP`）；两行时**上行不短于下行**，
避免头轻脚重。

> **删掉的两条**（原始规范里有，实测站不住）：
> ① 「副标题加 0.5~1pt 字间距」—— 中文技术文档不用字距拉层级，那是海报做法；
>    叠印／重排里加字距要逐字定位，断行判据全废。层级已由字号差 + 字重差 +
>    段间距表达。
> ② 「型号比中文主标题大 1~2pt」—— 型号属「原样保留」项，人为放大即失同源。

## 6. 机器判据

见 `toc-and-nav.md` §7 的八道关。与封面直接相关的是：

- **F 保留项**：封面页的型号／商标／地址／编号在成品上仍在（只对叠印路线）；
- **G 残留英文**：白名单外的英文行 = 0；文字不越出页面；
- **H 封面对齐**：成品各块的对齐方式与源页一致（只对叠印路线）。

⚠ **F、H 两关的前提都是叠印。** 从零重建路线的封面是**另行编排**的，
逐块比对齐没有意义（那是设计选择，该由目检判断）；而重建把图表画成图元／
位图，源页文本层里的刻度值在成品文本层里本就不存在，拿它比会满屏假阳
（实测一张图表报 29 条「保留项失踪」，图其实完好无损）。
