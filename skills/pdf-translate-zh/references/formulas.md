## 1. 多行算式：`RALIGN` 空格填充右对齐

工程手册里的算式常排成「说明 + 数值右对齐成列」的形式：

```
指重表读数（提离井底）                    120,000 lbs
− 工作钻柱重量                          − 95,000 lbs
────────────────────────────────────────────────────
= 震击器载荷                              25,000 lbs
```

叠印时若把整块当成一段散文写，就压成了一句话，算式结构全丢。

⇒ `RALIGN`（`chr(3)`）记号：**用空格填充**把右段顶到右边界，逐行还原。

```python
"Weight indicator reading (off bottom)\x03120,000 lbs\n"
"− String weight\x03− 95,000 lbs\n"
"= Jar load\x0325,000 lbs"
```

与 `LEADER`（点引线）同一套填充算法，只是填充字符不同：
`LEADER` 填 `.`（目录），`RALIGN` 填空格（算式）。
两者都必须**实测收敛**（见 `toc-and-nav.md` §2）。

## 2. 行高系数必须分档

一律用 1.90 会把多行算式压到 6pt。

```python
_f = 1.90 if 发生折行 else 1.34
```

- **发生折行**（估算不准，宁小勿溢）→ 1.90；
- **文本自带换行、且各行都不折** → 真实需求只有 ~1.34。

判据：`_nlines(probe) > probe.count(chr(10)) + 1`。

## 3. 公式行**不参与几何对齐判据**

带 `RALIGN` / `LEADER` 记号的条目一律自己管对齐。
再叠一层「整行右对齐」或「居中」，填充算短一点就把整行推走，左边缘参差。

```python
if LEADER in zh or RALIGN in zh:
    ctr.discard(idx); rgt.discard(idx)
```

## 4. Symbol 字体的**造字区**（PUA）

α / β / Δ / ± / ° / ≤ / ≥ 等在 Symbol 字体里被编码到私用区
（PUA，U+F020~U+F0FF）。提取出来是 `` `` 这样的码位。若原样写入：

- **键对不上** —— 字典里写的是普通 `α`，永远 miss；
- 即便命中，微软雅黑**没有 PUA 字形**，渲染成方框（`check_glyphs` 会报）。

⇒ 一律先归一到真 Unicode（`keyclean.norm_pua()`，映射依 Symbol 字体的
标准编码表，偏移 `0xF000`）：

| PUA | 真字符 | PUA | 真字符 |
|---|---|---|---|
| U+F061 | α | U+F0B0 | ° |
| U+F062 | β | U+F0B1 | ± |
| U+F044 | Δ | U+F0B4 | × |
| U+F073 | σ | U+F0A3 | ≤ |
| U+F070 | π | U+F0B3 | ≥ |
| U+F0B7 | •（项目符号） | U+F0FC | ✓ |

⚠ **项目符号也在这一区**。实测 规范 F 全书用 U+F0B7 作项目符号，
未归一时该串首字符不是空白，`split()` 清不掉 ——
于是同一段文字产生**两个键**（带符号／不带符号），词表必漏一个。

实测用途：手册 D 用 α/β 作台肩间隙的测量标记
（与 手册 C 的 X/Y 同义），`β=______in. (mm)` 这类整行。

## 5. 上下标

- `N₂`（U+2082）、`°`（U+00B0）、`″`（U+2033）、`⁰`（U+2070 上标零）；
- **上标零 ≠ 度符号**。实测 Stator Dimension Report 用 `45⁰` 表达「45 度」——
  这是输入法误取，属**原文缺陷**，按度译出并记入附录 A 甲；
- `check_glyphs()` 只能抓「字体里没有该字形」的情况。
  上标零在雅黑里**有**字形，抓不到 —— 靠人读。

## 6. 堆叠分数

原版的 `4 ½` 在文本层里是 `4 1⁄ … 2`，**分母漂到串尾**。

⇒ 复原规则：「分数标记（U+2044 或 `/`）之后的第一个孤立数字即分母」，
重组为 `4-1/2`。

分数在 `keep` 规则里要护住，但**必须带尾锚**：

```python
r"^\d+/\d+$"      # ✓
r"^\d+/\d+"       # ✗ 会把所有以分数开头的整行都吞掉（实测 规范 F 判据文字整段消失）
```

## 7. `zh()` 全角规范化里的**受保护片段**

数值、编号、图号不能被全角化。先把受保护片段挖空（`\x00n\x00`）
再做全角替换，最后回填：

```python
_PROTECT = [ r"https?://\S+", r"www\.\S+", r"<[^>]+>",
             r"\d+(?:,\d{3})+(?:\.\d+)?",                     # 1,500
             r"\d+\.\d+", r"[A-Za-z]{1,6}\.\s?\d[\w.\-]*",    # Fig. 6-4
             r"[A-Za-z]{1,5}\d[\w.\-/]*",                     # XS21.39947P / T-20
             r"\d+\s*[-–]\s*\d+", r"\d+/\d+" ]
```

句点 → 句号仅在「紧跟中文字符」或「整串结尾且本串含中文」时发生，
`Fig. 6-4` 不受影响。全角标点两侧不留空格（含全角括号内外侧）。
**写单元测试断言**（`selftest.py`）。

## 8. 中文判据要含**全角标点**

判「这一行是不是残留英文」时，中文判据若只写 `[一-鿿]`，
`MSDS。` 这类整句译文的尾巴单独成行时会被误判 ——
`。`(U+3002) 不在 `一-鿿` 区间内。

```python
re.search(r"[一-鿿　-〿＀-￯]", s)      # 含 CJK 符号区与全角区
```

## 图内公式与平化歧义（避坑 79）

- **堆叠分数的分数线覆盖范围就是括号。** 文本层平化提取必然丢括号：
  `(RotorMajor + RotorMinor)/2 − StatorMinor` 平成一行后读作谁除谁全凭
  运气。凡译文里出现「A + B − C」且源版该处是分数排版的，一律回源版
  渲染图核对分数线罩住了哪几项。
- **勘定优先、存疑兜底**：能从上下文闭环确定分组的（量纲、物理定义、
  正负号语义，如 正配合=压缩 ⇒ 配合值=转子平均直径−定子小径），
  直接以显式括号／分式重排并记附录甲；不能闭环的保留原式加注附录乙。
- **图内说明性公式**与正文公式重复时：移入正文按公式规范排版，
  图内的平化公式条目抹除（图内排不出分数线，正文排得出）；
  图内只留测量示意。
