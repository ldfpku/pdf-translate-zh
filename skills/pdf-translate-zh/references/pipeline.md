# 规模化生产：模板册提取重建 + 多代理流水线（V3）

> V1 问「怎么塞回去」，V2 问「什么是内容」，V3 问「**怎么规模化生产而不失手**」。
> 实战依据：196 页整册手册（散文 50 页 + 82 个型号规格册 143 页 + 28 幅插图），
> 单轮产出全册，交付后仅两处用户反馈（均为图务，见避坑 73/74）。

## 1. 模板册判定与提取-重建制

**判定**：文档中是否存在「同一版式模板重复 N 次、只换数据」的区段？
（产品规格页、数据表册、检验记录页……）判据：抽 3 页做「标签集合」比对——
逐页提取粗体/彩色的字段标签文本，集合相同或高度重叠即模板册。

**命中后切换生产制：不翻页面，翻结构。**

```
① 结构化提取器   逐页「标签→值」提取（文本层直取，数字零转录）
② 标签字典       模板的字段标签是**闭集**（实测 82 页只有 26 个标签），译一次全册生效
③ 模板工厂       ReportLab 工厂按品牌样式重排，每型号 1~2 页
④ 逐项对账       提取值 ↔ 源页逐 token 比对 = 0 差异（「准确」的机器证明）
⑤ 逐型号实排     页对必须 N 页、紧凑必须 1 页（避坑 ㉓ 的模板册版）
```

### 提取器设计的四条实测教训

- **标签驱动，不写死字段模式**：同一模板的变体间字段含义会漂移
  （B=Bit to Bend 与 B=Overall Length 并存），按「页面上出现什么标签
  就提取什么」，不要预设 schema；
- **过滤按字体，不按坐标**：紧凑变体的标签 x 与全尺寸变体差 50pt，
  按 x 过滤必丢整表；尺寸字母（MyriadPro）、图表刻度（OpenSans 小号）
  按字体族剔除稳定得多；
- **逐字符碎片要按 x 间距并回**：个别页把 "10.6" 拆成 "1","0",".","6"
  四个 span（间距 <2.8pt 并回同 token），不并直接错列；
- **占位表也要忠实重现**：小规格无造斜数据时整表为「–」，这不是提取
  失败，照排。

### 图表类素材（模板册里的曲线图）

保留原图渲染，**坐标轴标题按源 span 坐标 redaction 后重写中文**，
刻度数字与图例（`400 GPM`）按图形语言保留。全册模板共用一套处理——
但**先确认标签在文本层**：同一册书里，规格曲线的标签是矢量、
示例曲线的标签却烧死在位图（避坑 74），必须逐图分路。

## 2. 多代理流水线：什么可以外包、什么必须中心化

| 工序 | 归属 | 理由 |
|---|---|---|
| 散文翻译（分块） | **外包**给翻译代理 | 供料结构化后质量稳定，且代理会主动发现原文笔误 |
| 图内文字转录+译名 | **外包**给视觉代理 | 机器给框、代理读字，绕开无 OCR 的限制 |
| 行业判定/术语表/语体 | **中心化** | 一致性的源头，进入所有代理的提示词 |
| 坐标（裁框/回叠/布线） | **中心化** | 代理给的坐标只能作候选，一律经同源检测或目检核验 |
| 装配/闸门/勘误 | **中心化** | 对账与质检不可分散 |

### 翻译代理的供料规范

- **结构化抽取稿**供料：逐行标注 `[H1]/[H2]/[B]/[I]/[LI]/[T]/[FIG]`
  （字号+字体+缩进推得），代理按块 DSL 输出（h1/h2/h3/p/bul/note/kv/tbl/fig）；
- 提示词三件套：**行业术语表**（必用、首现附英文）、**翻译规则**
  （物理断行不是语义边界；shall/must/should 映射；祈使句；禁 Markdown 记号）、
  **结构化输出 schema**（强制 JSON，装配层零解析歧义）；
- 分块以 15~22KB 抽取稿为宜（大章拆段），一块一代理并行；
- **要求代理为原文笔误加 `err` 标注**——实测 10 个代理带回 22 处
  原文缺陷（拼写误、漏逗号、陈旧交叉引用），直接汇入附录 A 甲。

### 视觉代理的图务规范

- 供料 = 描红核查图（检测框）+ 干净裁图 + 检测框坐标清单 + 术语表；
- 代理只做两件事：**转录框内英文、给出译名**；坐标一律照抄检测值，
  禁止自造（`KEEP`=保留 / `SKIP`=碎屑 / `STRIP`=只描白 三个哨兵值）；
- **要求代理附 `crop_bad` 质检字段**——描述裁框是否裁进正文、截断
  标签、混入页码。实测 9 个代理带回 5 处真裁框问题，是闸门之外
  最有效的人工目检替代；
- 代理的人工修正框（漏检补框、截断合并）应用后**必须目检**；
  两轮猜不中的坐标，画网格实测（`_z_grid` 法），不再猜第三轮；
- 回叠一律 `apply_raster(smart=True, grow=6)`：描白框先收紧到真实
  文字行、同图字号统一（避坑 77）；贴片底色**采样环境色**而非纯白、
  文字黑/白随底色亮度（避坑 77b）；人工特设框豁免收紧、共享字号；
- **修复效果必须在干净重裁的图上验证**——上游清单空转时 apply 会在
  已回叠图上叠涂，新旧涂层互相遮掩，目检结论全部失真（避坑 78）。

### 汇合与装配

- 代理返回全部落盘（`prose_zh.json` / `figlabels_zh.json`），装配层
  只消费落盘产物——可重跑、可追溯、可局部修补；
- 术语一致性在汇合处再兜一道：跨代理的同物异名（挠性轴/柔性轴）
  用 `ZH_FIX` 映射统一；
- 图-图题**真值布线**（见 figures.md §13）后装配层零启发式。

### 跨册并行（同时翻译多份文档）

- **并行单位是「册」，不是「页」也不是「工序」**：一册交给一个代理全权
  走完（route → 提取 → 翻译 → 装配 → 闸门），产物全部落盘在本册工作区，
  协调者只读落盘产物汇总。按页跨册扇出会把协调上下文炸掉——批量任务
  一律**逐文件落盘、最后单独汇总**，严禁全量单批。
- **先中心化、再放行**：全部待译册先统一做行业判定与**跨册术语底座**
  （同客户多册时术语必须跨册同物同名），冻结后写进每个代理的供料提示词；
  并行期间代理不得自行新增术语，候选译名回传协调者裁决后并入底座。
- **图务与超分不占协调通道**：`sr.py` 是本地 GPU 进程（权重 67MB 随
  skill 自带，不联网、不进模型上下文），按目录整批处理、逐图秒级——
  多册排队跑即可，无需为它做并行设计。
- **汇合三查（交付前）**：合并词表 `batchwork.dupes()` = 0；跨册术语
  一致性（`ZH_FIX` 兜底）；每册各自六道关/八道关全绿。
- 少量并行用委托子代理（每册一个）；长册或大批量改用独立 agent 进程
  （一册一进程），分界同多代理流水线的成本结构。

## 3. 美术页三件套：封面 / 章扉页 / 整页设计图

三者同法（P 级思路的像素版）：

```
redaction 全部英文 span → 整页高分辨率渲染 → PIL 按源 span 坐标/颜色/字号回写中文
```

- 品牌美术、背景摄影原样保留；商标与品牌口号不译；
- **整页设计图不是背景**：判「整页尺寸即背景」会把整页图册页误杀，
  其中的小位图另立门户导致腰斩（避坑 73 的上游）。判据加一条：
  页面含成组标注文本（部件名、引线）的整页图元 = 设计图页，走本法；
- 一词多义标签按**几何消歧**（"Transmission" 下方 15pt 内有 "Housing"
  续行 = 传动壳体，孤立 = 传动总成），不能只按词典；
- ReportLab 装配整页图用 `NextPageTemplate` 双模板，注意避坑 75 的
  三个撕页坑，构建收尾跑 `collapse()` + 「空白页 = 0」判据。

## 4. 浅字深底的表头（检测第二盲区）

暗字检测（`detect_raster_labels`）只认深色墨迹——**绿带/蓝带上的白字
表头整批漏检**（实测一册 6 张烧死表格的表头全部漏，sweep 也不报，
因为那里「没有深色文字块」）。

⇒ `figlabel.band_cells(png, rgb)`：按**底色连通域**求表头单元格框，
`repaint_cell()` 整格重绘 + 居中写白字中文。数值/单位单元格传 `None`
保留原样。行团块手术（只译「& UP」类单元格）同理按列 x 带定位。

## 5. 交付后的缺陷响应（V3 节奏）

用户点名的永远是样本。V3 新增的对账工具让「定根因 → 全书判据 →
复验归零」有了固定抓手：

- 图务类：先跑**图题-图数全书对账**（每条「图/表 N.M」所在页的图数），
  串位一处即全查配对真值；
- 内容类：分块重译只动对应 `prose_zh.json` 块，装配层不变；
- 模板册类：改提取器后全 82 型号重跑对账，不逐页手修。

## 6. 增补（某客户整册手册实战第二轮）

- **矢量源表格**：供料阶段就按源页几何抽取成结构化行列，禁止让翻译
  代理从平文本重组表格（实测行列错位、整列空缺，且闸门难以发现）；
- **楼层对账常驻闸门**：浮动元素（图/表）的前导小节号与源版真值
  逐条对账（避坑 80），交付前必跑，用户点名一处先查全书；
- **映射幂等**：元素处置形态升级（图→真表）时，同步降级布线映射
  （避坑 82），管线每环重复执行不得产生「复活」或叠层。
