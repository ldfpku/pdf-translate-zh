# 幻灯片 / 演示文稿（PowerPoint 导出 PDF）

> 主干见 `SKILL.md` §0.5「版面三级」。本册讲**第四类文档**：培训讲义、技术
> 汇报这类由 PPT 导出的 PDF。实测依据：79 页某客户《钻井震击器失效机理》
> 培训讲义整册交付（六道关全绿 + 逐页目检 + 两轮用户目检整改）。

> 幻灯片既不是散文手册，也不是工程图纸，**两套现成路线都不能照搬**。

## 1. 定级：幻灯片是 P/H 级，但正文列表要重排

对幻灯片问 §0.5 那三个问题，答案很特别：

| 问题 | 答 | 含义 |
|---|---|---|
| 坐标有语义吗 | **有** | 照片位置、引出箭头指向、引注落点就是内容 |
| 格子要回填吗 | 否 | — |
| 删掉版式重排后信息有损吗 | **有损** | 一页 = 一个设计单元，重排即毁 |

⇒ **整页走叠印保位**（照片、箭头、母版、页眉页脚一概不动），
**但页内的正文列表必须整列重排**。这是幻灯片独有的一条：

> **原版的条目间距是按「英文占几行」排的，不是内容的一部分。**
> 内容是**条目的次序与层级**。

英文两三行的条目译成中文常只剩一行。逐条钉回原 y：条目之间留下一个个空洞；
个别长条目折行后又压到下一条上（且**未命中/溢出/残留英文/缺字四关全都
看不见重叠**）。两种毛病同源，只有整列重排能一并解决。

重排规则（`slidekit.layout_flow`）：

- 起点沿用**原列表首条**的位置；
- 间距取**原版条目间距的中位值**（那是设计者定的节奏，别自己发明）；
- 层级由**各自的原缩进**保持（tx0 不动）；
- 同级字号取齐；
- 整列排不下时**先缩间距、再降字号**，硬下限 6.5pt。

**不参与重排的**：标题、图内引注／照片标签。引注是指着图上某处的，
中心一挪指向就错 ⇒ 以**原墨迹中心**为锚居中，只做适度加宽。

## 2. 语义单元：物理行不是单元

PPT 导出的文本层碎得厉害。`slidekit.units()` 一次解决四件事：

### 2.1 项目符号有**两种形态**

```
形态 ①  自成一行     符号 x=96.1 ┊ 正文 x=122.8      ← 两个 line
形态 ②  行内首字符   符号与正文同属一个 span
```

按 span 框取正文起点对形态 ② 是**错的** —— tx0 落在符号自己身上，抹除框从
那里起算就把符号一并抹掉（实测整页项目符号消失）。
⇒ 必须用 **`get_text("rawdict")`** 取逐字符包围盒。
形态 ① 的裸符号行不是单元，要**认领**给右邻同基线那一行；不认领的话，
那一页的子条目一条都认不出，整段正文并成一块散文写出去。

### 2.2 续行判据不能要求「更深的缩进」

续行与本条正文**恰好齐平**（实测同为 162.2）。写成 `tx0 > L.tx0 + 6`
一条也接不上，物理断行就成了翻译单元边界 —— V2 公理明令禁止的那件事。
⇒ `tx0 >= L.tx0 - 2`，另加「居中块续行」一路（中线取齐而左右不齐）。

### 2.3 分组必须**先按列聚类**

沿 y 序贪心吞并会把并排的几条引注串成一条 —— 它们 y 交错、只在 x 上分得开
（实测一页三条照片引注被串成一条 8 行的怪串）。

### 2.4 字号/字色取**主导 span**，不取 max

行尾常挂一个更大字号的**段落标记空 span**。取 max 会让该行与本组「跨字号」
不符而接不上，一句话被切成两条。

## 3. 字色是内容

母版正文常**不是黑色**（实测深藏青 `#003366`），小标题另有一色
（`#0070C0`），而作者会用红/绿标注重点结论（`#00B050` 标了「RARE /
LESS COMMON」几条）。一律写成黑的，就把这层视觉编码抹平了。

⚠ 强调色可能只落在折行条目的**第二行**上，按首行取色会丢掉。
⇒ 判据：**一组之内只要出现非正文色，整条取该色**（中文一句话是一个单元，
强调落在整条上）。「正文色」= 本页出现最多的字色。

## 4. 项目符号：重排后必须重绘

原版 Wingdings 字形搬不到新位置。但这些符号本就是**实心方块／短横** ⇒
`slidekit.bullet_ink()` 在**源页**上量出墨迹框与颜色，用 `draw_rect`
原样重绘并随正文平移（`dy = 新框.y0 − 原墨迹.y0`），位置、大小、颜色照旧。

对**不重排**的条目（图内引注）则相反：抹除框从**正文起点**起算，
原版符号字形原样留着 —— 重绘反而对不准。

---

## 5. 字号：×0.92 起排

拉丁字面高约为字号的 0.7，中文是满格。等号排出来中文明显偏大。
起排取 `原字号 × 0.92`，再按实测降号，**同页同级向下取齐**。

## 6. 常见页型速查

| 页型 | 处置 |
|---|---|
| 标题页 | 标题/副标题原位叠印；人名、公司名保留原文 |
| 版权页 | 整段叠印 |
| 纯项目符号页 | 整列重排 |
| 列表 + 右侧照片 | 重排，右界按**该条新 y 位置**避开照片（高度与右界互相依赖，先按单行估、排完复核一次） |
| 纯照片页 + 红色类型标签 | 标签原位居中叠印，**保留红色** |
| 图表页（载荷包络图等） | 整幅是位图 ⇒ 走图内回叠，见 §7 |
| 实物照片 + 引注框 | 引注按原墨迹中心叠印；黄底引注框要**显式给底色** |

## 7. 图表页：斜排标注也能贴回

此前这类标注只能「保留英文 + 附录说明」，理由是 `insert_textbox` 的
`rotate` 只认 90° 整数倍。**这条限制已解除**（`vectext.slant()`）：

- 写字改走 `insert_text(morph=(pivot, matrix))`，角度任意；
- 描白改用**旋转四边形**（`draw_quad`）—— 轴对齐矩形会把标注旁边的曲线
  连带啃掉一大块，而这类标注恰恰就压在曲线上。

内容层只需给**基线两端点**（从带坐标网格的出图上读），角度、长度、中心
由程序算。⚠ 两处旋转的**符号相反**，详见避坑 85。

图表页的分工：

| 部分 | 处置 |
|---|---|
| 图题、横轴标题 | 直接贴 |
| 竖排纵轴标题 | `rot=90`（自下而上，与原版一致） |
| 沿曲线斜排的图例说明 | `vectext.slant()` |
| 符号本身（P、Q、Ta、T1~T4、PQ、PT3T2…） | **保留原文** —— 正文按名引用（「Ta：28,381 ft-lbs」），必须与正文一致。只译等号右边的释义 |
| 曲线上的钢级代号（E-75/S-135…） | 保留，属型号标识 |

⚠ 同一份文档里同名曲线可能记号不同（实测一图作 `PT4T2`、另一图作
`PT3T2`）—— **照抄，不要统一**，并记入附录 A。

## 8. 装配骨架

```python
import slidekit as sk

for pi, prec in enumerate(pages):
    page, spage = doc[pi], src[pi]          # spage = 干净源页，量墨迹/找障碍
    us = [u for u in sk.units(spage) if u["role"] != "foot"]
    # …查词表得 u["_zh"]，"" = 保留原文不抹不写…
    flow, rest = sk.flow_items(us)

    for u in flow:                          # 重排条目：连符号一起抹
        r = fitz.Rect(u["ink"])
        if u["brect"]:
            r |= fitz.Rect(u["brect"])
            u["_bink"], u["_bcol"] = sk.bullet_ink(spage, u["brect"])
        page.add_redact_annot(r + (-1, -1, 1.5, 1))
    for u in rest:                          # 原位条目：从正文起点抹，留符号
        ink = fitz.Rect(u["ink"])
        rx0 = (u["tx0"] - 1) if u["bullet"] else ink.x0 - 1
        page.add_redact_annot(fitz.Rect(rx0, ink.y0 - 1, ink.x1 + 1.5, ink.y1 + 1))
    page.apply_redactions(images=fitz.PDF_REDACT_IMAGE_NONE,
                          graphics=fitz.PDF_REDACT_LINE_ART_NONE,
                          text=fitz.PDF_REDACT_TEXT_REMOVE)

    for u, zh, box, s in sk.layout_flow(spage, flow, [u["_zh"] for u in flow], rest):
        dy = box.y0 - u["ink"][1]
        if u.get("_bink") is not None:
            b = u["_bink"]
            page.draw_rect(fitz.Rect(b.x0, b.y0 + dy, b.x1, b.y1 + dy),
                           color=None, fill=u["_bcol"])
        write(page, box, zh, s, align=0, color=rgb(u["color"]), force=s)
    # …rest 原位写：标题左对齐、引注以原墨迹中心居中…
    sk.subscript_pass(page)                 # 化学式真下标
```

**收尾三件事**（缺一不可）：

1. `doc.subset_fonts()` 后再存 —— `insert_font` 是**逐页**嵌入的，
   不子集化则每页各带一份完整雅黑（实测 3 页文档从 0.30 MB 涨到 22.6 MB、
   79 页涨到 31 MB，见避坑 96）；
2. `sk.orphans()` 断句体检必须为 0；
3. 逐页出图目检 —— 六道关看不见「位置对不对」。
